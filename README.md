Velvet Vault — The Meridian Job. A one-night stealth heist in the original city of Vesper: plan the entry route, buy tools with a cut of the take, cross a guarded bank hall under sweeping vision cones and cameras, crack the Meridian Vault, then drive the getaway van to the rendezvous with police on your tail. Top-down 2D, keyboard and mouse, no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
